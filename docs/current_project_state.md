## 1. Physical Workspace Inventory

### 1.1 Local Code Structure
- **Root Orchestration Scripts:**
  - `run_pipeline.py`: Main entry point for end-to-end execution of a single model and dataset.
  - `run_missing_generations.py`: Script to iterate through missing model outputs on IBM Debater and Kialo.
  - `run_tri_dataset_evaluation.py`: Monolithic script to unify Perspectrum, IBM, and Kialo, compute embeddings, and evaluate two-stage coverage.
  - `inspect_tri_datasets.py`: Diagnostic check for files across the three datasets.
  - `sync_to_hpc.ps1` / `sync_to_hpc.bat` / `create_hpc_sync_package.py`: Infrastructure to package updated code and transfer to IITGN HPC.
- **Source Modules (`src/`):**
  - `src/data_prep/`: Parsers for Perspectrum, IBM Debater, Kialo, and prompt construction.
  - `src/generation/`: `generate_llama.py` (Hugging Face batch generator), `llm_config.py`, `postprocess_generations.py`.
  - `src/embeddings/`: Dense embedding wrappers (`embed_model.py`, `embed_perspectives.py`, `embed_llm_outputs.py`).
  - `src/analysis/`: Coverage metrics, diversity, threshold calibration, NLI stance classification, two-stage evaluation, paper artifacts.
  - `src/training/`: Scripts to prepare NLI training data and fine-tune DeBERTa.
  - `src/utils/`: IO utilities and logging.
- **Configurations (`configs/`):**
  - `configs/config.yaml`: Central YAML specifying LLM hyperparameters, prompt templates, aspects, dataset paths, and embedding configurations.
- **Tests (`tests/`):**
  - 11 unit test files covering IO, metrics, NLI stance classification, and CLI entry points.

## 4. Manuscript State

- `paper_draft.tex` and `paper_draft.md` are drafted around the premise of "The Scaling Paradox" and "Universal Sycophancy".
- The inverted-U scaling curve in Table 2 was observed with uncalibrated parsing rates (e.g. Qwen2.5-1.5B had parse failure rates over 99% in earlier runs).
- Stance imbalance was interpreted as "sycophancy" without a controlled prompt-framing experiment.
- Universal blind spots (238 claims) were computed using greedy maximum similarity without bipartite matching or cluster grouping.
